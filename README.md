# Privacy Shrub Service — Website v1.3

## Preview
Extract the entire ZIP. Open `index.html` in Chrome with `styles.css`, `script.js`, and the `images/` folder alongside it.

## Consultation form
Formspree endpoint: `https://formspree.io/f/mzeerkya`

The form uses asynchronous POST with validation and visible success/error messages. No customer data is stored in the browser. It sends name, email, location, project size, message, and consent. A hidden spam-trap field is included.

### Test before publishing
1. Fill in the form with **TEST SUBMISSION** in the project description.
2. Submit once while connected to the internet.
3. Confirm the success message and the submission in Formspree > Submissions.
4. Check `privacyshrubservice@gmail.com` for the notification, including Spam.
5. If the request does not appear, review browser developer tools and Formspree settings.

**No live submission was performed during packaging.**

## Publish on GitHub Pages
Create a repository and upload the extracted files to the repository root. Under Settings > Pages, choose Deploy from a branch, main, / (root). Test the published site again.
